Descargas automáticas de MercadoLibre

Programa cuándo debe abrirse Chrome, preparar la planilla y descargar el Excel.

Se ejecuta una vez cada vez que inicias sesión.
Puedes agregar, modificar o eliminar horarios.
Conectando con el programador de Windows…
La programación funciona aunque Chrome esté cerrado, siempre que Windows esté encendido y hayas iniciado sesión. MercadoLibre debe conservar una sesión válida en Chrome.
